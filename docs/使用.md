# 使用

[← 返回首页](../README.md) · [安装](安装.md) · [进阶](进阶.md)

打开对话框旁或输入条右侧的 **「生图」** 按钮。面板用于选素材和准备请求；任务记录和执行 AI 设置在 **设置 → 图片 / 视频提示词**。

## 先选栏目

| 栏目 | 需要输入什么 | 点击哪个按钮 |
| --- | --- | --- |
| 生文案 | 书籍 ID 或链接、文案要求 | 准备文案请求 |
| 扒素材 | 竞品名称、平台、素材落地目录 | 准备抓取请求 |
| 爆款分析 | 勾选的图片或视频 | 准备分析请求 |
| 生图 | 图片、视频或参考文档，可补充来源文本 | 准备生图请求；需要出图时使用对应引擎按钮 |
| 生视频 | 图片或视频，可补充来源文本 | 准备视频请求 |

每个准备按钮都会把请求放进输入框，**按 Enter 发送后才执行**。发送前可以修改要求；也可以先点「复制请求」。

生视频栏目当前产出提示词与分镜，面板尚未接入视频出片引擎。

## 扫描与勾选素材

生图、生视频和爆款分析使用本地素材：

1. 点「选文件夹…」选择素材目录，或填写绝对路径。
2. 选择「层数」，再点「扫描」；`0` 表示只看当前目录，默认向下找 4 层。
3. 素材列表默认收起，点「展开列表 ▸」查看并勾选；支持全选与取消。
4. 填好产物目录，点「记住」，供后续任务使用。

常见格式包括 PNG、JPG、WebP 等图片，MP4、MOV、WebM 等视频，以及 MD、TXT、SRT 等文本。**扩展名能被扫描，不代表当前浏览器一定能预览或解码该格式。**

生图栏目显示视频、图片和文档三列；生视频与爆款分析显示视频、图片两列。生文案、扒素材使用各自的输入区。

找不到子目录中的素材时，先调大扫描层数。无法使用宿主目录选择器时，可以直接填写路径，或尝试「本地挑文件夹」。

## 图片与视频怎么搭配

| 素材 | 在「生图」中 | 在「生视频」中 |
| --- | --- | --- |
| 图片 | 整理图片提示词，可继续交给网页引擎出图 | 整理图生视频提示词，说明首帧或参考图用途 |
| 视频 | 先观察或抽帧，再整理图片提示词，可继续出图 | 整理带时间码的分镜和视频提示词 |

「用 Grok 生图」或「用 ChatGPT（Edge）生图」至少需要勾选一个图片或视频素材。选网页出图之前，按[进阶设置](进阶.md#网页出图)准备浏览器与引擎账号。

## 添加小说正文或章纲

在生图或生视频栏目展开「来源文本」：

1. 点「展开正文」粘贴文本，或用「加文本文件」读取本地文本。
2. 也可以用「按路径加」输入多个绝对路径，以换行或分号分隔。
3. 勾选界面中的「按来源文本生图」，把正文作为本次创作材料；生视频请求也能带入来源引用。
4. 勾选至少一项素材，再准备对应请求并发送，由会话按主要情节整理提示词或分镜。生图可以勾选参考文档，生视频需要图片或视频素材。

来源正文用作所选素材的补充材料。正文会先保存为本地文件，请求带材料路径与字数，避免把长文全部塞进输入框。来源文本保存失败时，本次派发会取消并显示原因。

## 生文案与扒素材

**生文案**：填写书籍 ID 或链接、文案要求，准备请求并发送。会话通过可用浏览器读取免费章节作为材料；登录状态需要你提前准备。

**扒素材**：一行填写一个竞品名称，平台可选「自动」「广大大」「AdXray」。按需指定落地根目录，再准备请求并发送。名称后可写「第2页」或 `:1-2` 指定页码；抓取与下载由会话的浏览器工具执行。

## 草稿与任务记录

收起面板、点击外部或按 Esc 会保留当前页面中的草稿；正文、书单、文案要求、勾选与本地挑选文件暂存在内存中。丢弃草稿请点「清空草稿」，刷新或关闭页面前先保留需要的内容。

在 **设置 → 图片 / 视频提示词 → 任务记录** 查看最近派发记录，展开记录可查看产物；「接着做」把续做说明写回输入框，仍需发送后执行。详细状态与失败重试的支持范围见[进阶](进阶.md#任务记录与续做)。

## 常见问题

| 遇到的情况 | 先检查什么 |
| --- | --- |
| 点按钮后任务没开始 | 请求是否已进入输入框，是否按 Enter 发送 |
| 素材显示为零 | 目录是否正确、扫描层数是否足够，当前栏目是否使用本地素材 |
| 看不到素材列表 | 点「展开列表 ▸」；列表默认收起 |
| 「用引擎生图」按钮不可用 | 至少勾选一个图片或视频素材；文档和正文不能单独启用该按钮 |
| 生视频后没找到视频文件 | 当前栏目输出提示词与分镜，实际出片需要另外的生成工具 |
| 浏览器任务无法继续 | 浏览器工具是否连接、网站是否登录、执行 AI 与引擎是否选对 |
| 找不到生成的图片 | 检查素材目录的 `grok-output`，具体路径见[进阶](进阶.md#输出放在哪里) |
