## 执行 AI 与生图引擎

这两个选项负责不同步骤：

| 选项 | 负责什么 | 在哪里设置 |
| --- | --- | --- |
| 执行 AI | 阅读素材、分析并编写提示词 | 设置 → 图片 / 视频提示词 → 执行 AI（B） |
| 生图引擎 | 使用提示词生成实际图片 | 生图面板最后的执行选择区域 |

执行 AI 默认是「本会话（默认）」，也可选 Grok 或 ChatGPT 网页。生图引擎提供 Grok、ChatGPT（Edge）；生视频与爆款分析的面板不提供出图引擎。

界面中的角色字母对应以下流程：

| 字母 | 白话说明 |
| --- | --- |
| A | 导演规则：指导提示词怎么写 |
| B | 执行 AI：负责理解素材并写提示词 |
| C | 提示词：交给生成工具的创作要求 |
| D | 生图引擎：负责生成图片 |
| E | 成图：回收并保存到本地批次目录 |

导演规则全文可在设置页「生图逻辑（A）」查看和复制；当前界面提供阅读与复制。

## 网页出图

1. 准备能操作 Edge 登录态的浏览器工具，并确认目标网站已登录。
2. 在生图栏目扫描并勾选图片或视频素材。
3. 选择生图引擎、清晰度、画幅与每条提示词的张数。
4. 点击「用 Grok 生图」或「用 ChatGPT（Edge）生图」。插件建立批次，并把执行请求放入输入框。
5. 检查请求后发送，让会话驱动网页出图、保存并核对本批产物。

清晰度、画幅和张数会写入请求与批次计划；**这些选择不构成实际分辨率、费用或成功率保证**，最终受网站与生成结果影响。

引擎在建立批次时绑定。需要换引擎，应新建批次；续做同一批仍使用其原引擎。

仓库保留了 Grok 通道的真实账号取图记录。ChatGPT 通道已有实现与离线检查，但原有文档尚未提供真实账号的完整取图验收；实际使用时需要核对图片是否真正保存。历史记录和接口说明见[开发](开发.md#网页出图的接口与历史验证)。

## 输出放在哪里

**「产物目录」与网页生图批次使用不同位置。** 按当前实现查找：

| 内容 | 位置 |
| --- | --- |
| 拆帧、分析卡片、提示词草稿等中间结果 | `产物目录/process/时间-素材名/` |
| 提示词与文案等最终文本 | 派发请求中指定的产物路径 |
| 单独保存的来源正文 | `产物目录/source/` |
| 网页生图批次与成图 | **`素材目录/grok-output/批次ID/`** |
| 素材处理状态与派发历史 | 素材目录中的 `.dsh-video-prompt/manifest.json` |
| 面板记住的配置 | DSH 数据目录中的 `dsh-video-prompt/state.json` |

`grok-output` 是兼容旧版本的目录名，Grok 和 ChatGPT 批次都使用它。每一批有独立目录，计划、执行说明、来源文本、图片与账本保存在同一批中。

默认素材目录为 DSH 数据目录下的 `dsh-video-prompt/media`，默认产物目录为同处的 `runs`。面板点「记住」保存的新路径优先用于后续任务。

## 任务记录与续做

设置页的「任务记录」展示最近派发记录，保留最近 30 条。「接着做」把续做说明准备到输入框，由你发送后继续执行。

网页生图批次另有基于计划、账本与文件校验的详细状态接口，提供以下能力：

| 能力 | 当前支持范围 |
| --- | --- |
| 续做同一批 | 使用原批次 ID 重新准备计划，在原目录继续补齐 |
| 仅重试失败项 | 输出失败项清单与原因，再由会话执行；接口不自动驱动网页重跑 |
| 取消标记 | 记录取消意图；正在执行的浏览器任务仍需要在会话中停止 |
| 产物校验 | 可核对文件是否存在、字节数与哈希；详细查询方式见开发文档 |

设置页的派发记录与批次详细状态是两份记录；批次完整状态与控制接口目前没有全部接入设置页。

## 技能管理

设置页的「技能电池」列出插件携带的七个技能。它们分别服务于视频观察、提示词整理、素材分析和导演规则，来源台账见[技能清单](../skills/MANIFEST.md)。

- 「拔掉」停用对应技能，状态会记住；「装回」重新注册。
- 新增技能包后，点「重扫技能包」补充注册。
- 修改已有技能正文后，完全重启 DSH Desktop，加载新正文。

普通使用可以保持默认配置。
