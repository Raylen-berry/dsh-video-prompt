# 安装

[← 返回首页](../README.md) · [下一步：使用](使用.md)

## 安装前准备

| 想用的功能 | 需要准备什么 |
| --- | --- |
| 面板、素材整理与提示词任务 | DSH Desktop，以及已配置的会话模型 |
| 下载插件源码 | Git；也可使用 GitHub 的 Code → Download ZIP |
| 网页出图、免费章节或竞品素材任务 | 可操作已登录浏览器的会话工具，例如 [浏览器插件](https://github.com/Raylen-berry/dsh-browser-live)；接管日常浏览器需按其教程配置 |
| 使用内置视频抽帧脚本 | Python、FFmpeg 与 ffprobe；只有扫描目录时，ffprobe 缺失会让时长和分辨率留空 |

网页操作能力和网站登录状态需要单独准备。插件会把所需步骤写进请求，具体执行由会话中的助手完成。

## 安装步骤

### 1. 下载源码

在 PowerShell 中执行，路径可以自行修改：

```powershell
$pluginDir = 'D:\DeepSeek\dsh-plugins\dsh-video-prompt'
New-Item -ItemType Directory -Force (Split-Path $pluginDir) | Out-Null
git clone https://github.com/Raylen-berry/dsh-video-prompt.git $pluginDir
```

使用 ZIP 时，先解压，再把 `$pluginDir` 设为**包含 `package.json` 的那一层目录**，例如 `D:\DeepSeek\dsh-plugins\dsh-video-prompt-main`。

### 2. 添加到 DSH

终端能使用 `dsh` 时运行：

```powershell
dsh plugin --profile web add "link:$pluginDir"
```

如果 `dsh` 不在终端的搜索路径中，也可以使用安装目录内的入口。下面的应用路径仅为示例，请换成自己的 DSH 安装位置：

```powershell
$dshAppDir = 'D:\DeepSeek\DSH Desktop'
node "$dshAppDir\node_modules\@deepseek-ai\dsh\lib\bin.js" plugin --profile web add "link:$pluginDir"
```

`link:` 引用的是本地目录，安装后请保留目录。普通安装无需运行开发测试命令。

### 3. 完全重启 DSH Desktop

等正在执行的任务结束，完全退出并重新打开 DSH Desktop。新增插件需要重启后才能加载宿主接口、界面入口与技能包。

检查两个入口：

- 对话框旁或输入条右侧的 **「生图」** 按钮。
- **设置 → 图片 / 视频提示词**，包含执行 AI、任务记录、生图逻辑和技能电池。

## 首次配置目录

打开「生图」面板，选择素材文件夹和产物目录，点「记住」。目录更改保存后立即用于后续任务。

未指定目录时，默认使用 DSH 数据目录下的 `dsh-video-prompt/media` 和 `dsh-video-prompt/runs`。网页生图批次另存于**素材目录的 `grok-output` 子目录**，详见[输出位置](进阶.md#输出放在哪里)。

## 更新

Git + link 安装，在没有自行修改源码时可运行：

```powershell
Set-Location $pluginDir
git pull --ff-only
```

若提示本地改动或分支分歧，先保留并处理自己的修改。ZIP 安装则重新下载、解压，再用新路径执行添加命令；原素材、成图与个人配置请先备份。

DSH 管理的安装方式可以使用：

```powershell
dsh plugin --profile web update dsh-video-prompt
```

更新后完全重启 DSH Desktop，确保宿主、客户端与技能正文一起加载新版本。

## 停用与卸载

临时停用，在 **设置 → 插件** 中关闭插件，并重启 DSH Desktop。

卸载命令：

```powershell
dsh plugin --profile web remove dsh-video-prompt
```

卸载后重启。需要保留素材、成图和配置时，先按下节备份。

## 换电脑

1. 在新电脑重新下载源码并安装插件。
2. 复制素材目录、产物目录，以及素材目录内的 `grok-output` 批次；仅克隆仓库不会带回这些文件。
3. 如需保留原配置，备份 DSH 数据目录中的 `dsh-video-prompt/state.json`；新电脑上重新核对目录路径和执行 AI。
4. 重新准备浏览器连接、网站登录态，以及所需的视频处理工具。

不同电脑的盘符与安装位置可能不同，以面板中保存的实际路径为准。

## 安装后没有入口

确认添加到了 `web` 配置、目录仍存在且包含 `package.json`，并已完全重启 DSH Desktop。面板能打开但目录选择失败，可能是宿主仍未加载新接口；重新启动后再检查。
