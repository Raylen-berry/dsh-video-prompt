# 通用创意基因与证据模型

## 1. 四层抽象

不要停在对象识别，也不要一步跳到“爆款原因”。

| 层级 | 定义 | 示例 |
|---|---|---|
| 原子线索 | 能直接定位到画面、声音、文字或指标的事实 | 红色大字、手持演示、雨声、首秒切脸部特写 |
| 功能模式 | 多个线索在内容中共同承担的作用 | 遮挡后揭示、身份反差、结果前置、可视化证明 |
| 创意机制 | 功能模式可能触发的注意、理解、情绪或信任过程 | 信息缺口、损失厌恶、自我代入、权威信任、爽感兑现 |
| 可迁移配方 | 保留机制但允许替换具体内容的结构 | 痛点首帧 → 现场演示 → 对比证据 → 低摩擦 CTA |

每个结论都要能从上层向下回溯。无法定位原子线索的“机制”只是猜测。

## 2. 单素材记录

| 字段 | 说明 |
|---|---|
| `asset_id` | 稳定编号，例如 `I0003`、`V0012` |
| `source` | 相对文件路径；视频证据附时间戳 |
| `comparison_group` | 平台 × 形态 × 题材/产品 × 目标行为等可比组 |
| `direct_observation` | 直接可见、可听或可读的事实 |
| `functional_pattern` | 线索在这条素材里承担的内容功能 |
| `mechanism_hypothesis` | 对注意、情绪、理解、信任或行动的解释 |
| `confidence` | 高/中/低，并注明缺失模态或歧义 |
| `metrics` | 原始值、单位、采集时间与来源 |

## 3. 通用分析轴

词表开放，按需填写，不强迫素材拥有所有字段。

### 策略层

1. **目标行为**：停留、完播、收藏、分享、评论、点击、询盘、购买、关注。
2. **目标受众与任务**：用户是谁，当下要解决、感受、避免或证明什么。
3. **主题/产品真相**：内容核心、真实卖点、事实边界、必须保留和禁止声称的内容。
4. **价值承诺**：观众继续看会获得什么结果、答案、体验或情绪回报。

### 内容机制层

5. **钩子**：结果前置、问题、冲突、反常识、身份圈定、演示、悬念、视觉异常、声音突变等。
6. **信息或叙事结构**：问题—解释—方案、前后对比、清单、实验、故事、追逐、揭示、循环等。
7. **张力与信息缺口**：什么未知、风险、矛盾、时间限制或预期差推动继续观看。
8. **证明系统**：演示、数据、过程、案例、权威、用户反应、实物、对比、截图或第三方证据。
9. **回报与 CTA**：承诺如何兑现，下一步动作是否自然且摩擦足够低。

### 主体与视觉层

10. **主体和角色**：人物、产品、对象数量、身份信号、外观、状态和相互关系。
11. **能动性与视角**：谁行动、谁反应、谁控制信息；第一人称、观察者、专家、使用者、对象或非人视角。
12. **动作与变化**：使用、制作、对抗、移动、遮挡/揭示、前后变化、身份切换、失败/成功。
13. **场景与语境**：地点、时间、天气、仪式、职业环境、真实使用场景和社会情境。
14. **构图与注意路径**：首视焦点、大小层级、前中后景、视线、负空间、裁切、遮挡、对称/倾斜、俯仰角、特写/全景。
15. **可见细节**：表情、眼神、手部、材质、衣着、道具、文字、数字、标志、色彩、光线和氛围。

### 时间、声音与分发层

16. **节奏与运动**：首秒变化、镜头长度、切换密度、运动方向、速度、停顿、循环点和动态模糊。
17. **语言与声音**：口播立场、句长、字幕密度、环境声、BGM、音效、静音与声画同步。
18. **包装与平台形态**：封面、标题、首行、缩略图、图文/轮播/GIF/短视频、标签、置顶评论和平台原生交互。

## 4. 媒体取证

### 图片

- 第一眼看见什么，第二眼读到什么，最后才发现什么。
- 文字是解释画面、制造矛盾，还是重复画面。
- 主体层级、视角、能动性、表情/手部、遮挡与揭示如何传达关系或价值。
- 生成式画面中的形体、文字或物理异常必须标注，不能当成创意优点。

### 视频

根据实际结构切段，不机械套固定秒数。至少记录：

- 开场发生了什么变化，观众何时理解主题和承诺。
- 每段新增了什么信息、证明或情绪，是否存在空转。
- 声音从何时开始；口播、环境声、动作声和音乐分别承担什么作用。
- 转折/证明是否可见，回报是否兑现，结尾是否形成循环或行动。

## 5. 跨样本归纳

### 无表现数据

报告以下独立维度，不强行合成一个漂亮分数：

- 覆盖率：含该模式的素材数 / 同组素材总数。
- 钩子显著度：是否位于封面、首视焦点或视频开场。
- 组合稳定性：与哪些元素经常一起出现，顺序是否一致。
- 可迁移性：替换主体、行业或表达后机制是否仍成立。
- 饱和风险：是否套路化、撞稿或容易引发审美疲劳。
- 证据置信度：是否覆盖画面、声音、文字和必要上下文。

使用“高频”“高显著”“候选机制”，不要写“导致爆款”或虚构提升比例。

### 有表现数据

- 先决定主要成功指标，避免观看、互动、转化混成一个目标。
- 在同平台、同账号/来源、相近发布时间与形态中比较；必要时使用播放速度、互动率、完播率或转化率。
- 比较“有该模式”和“无该模式”的中位数/分位数，并报告样本数。观察离群点和反例，不只看平均值。
- 只有正样本时，数据只能为样本加权；要估计关联，需要普通/失败对照。要声称因果，需要实验或更强设计。

## 6. 元素卡

进入推荐列表的模式至少包含：

- 模式名称、层级和作用阶段
- 直接证据：素材 ID、画面/声音/文字、视频时间戳
- 出现范围 `n/N` 与所在可比组
- 机制解释与置信度
- 表现关联或“未验证”
- 可迁移变量：哪些必须保留，哪些应该替换
- 饱和、事实、版权、安全和平台风险
