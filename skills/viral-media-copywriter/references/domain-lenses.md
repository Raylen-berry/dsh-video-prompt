# 内容类型路由镜头

先按素材真实目的选择一个主镜头；必要时加一个辅镜头。不要让类型模板覆盖素材证据。

## 商品、电商与应用

额外检查：

- 产品在几秒内被识别，具体痛点/使用情境何时出现。
- 卖点是否由动作、细节、前后对比或结果证明，而非只靠形容词。
- 产品露出比例、手部操作、材质/状态变化、包装与品牌一致性。
- 信任信号、异议处理、价格/稀缺信息和 CTA 摩擦。

常见配方：`痛点可视化 → 产品动作 → 证据/结果 → 异议化解 → CTA`。

## 知识、教程与观点

额外检查：

- 受众问题是否具体，结论是否前置，概念是否在一个例子中落地。
- 可信度来自数据、演示、来源、经验还是可复现步骤。
- 信息密度、认知台阶、屏幕文字和口播是否互补。
- 标题是否夸张超过正文证据。

常见配方：`反常识/痛点 → 一句话结论 → 解释/步骤 → 示例证明 → 可执行下一步`。

## 剧情、故事与虚构内容

额外检查：

- 谁想要什么、谁阻止、失败代价、信息缺口和不可逆选择。
- 角色身份、能动性、权力/关系变化由什么动作和证据表现。
- 视角选择、表情/眼神/手部、遮挡/揭示、身份前后反差和场景压力。
- 情绪回报是爽感、治愈、惊讶、恐惧、悔恨、浪漫还是正义兑现。

常见配方：`异常事件 → 身份/动机缺口 → 压力升级 → 证据揭示 → 关系或权力反转 → 情绪回报`。

涉及浪漫或性张力时角色必须为成年人；胁迫、跟踪或虐待可以作为冲突，但不能被包装成现实中的同意或爱情证明。

## 生活方式、审美与氛围内容

额外检查：

- 观众是在代入身份、向往环境、学习品味，还是获得舒缓/陪伴。
- 构图、色光、天气、材质、镜头运动、环境声和音乐如何共同建立气质。
- 是否有一个可识别的人物动作、物件或仪式，避免只有空泛“高级感”。
- 文案应补充画面含义还是保持留白。

常见配方：`身份/情境锚点 → 感官细节 → 小动作或仪式 → 情绪命名/留白 → 收藏或分享理由`。

## 转变、前后对比与挑战

额外检查：

- 起点、过程、终点使用相同尺度和条件，避免虚假对比。
- 变化由哪一刻被清晰看见；遮挡/切换/并列/分屏如何强化揭示。
- 时间、方法、限制和失败尝试是否交代。
- 结果是否可验证，是否存在健康、金融或效果夸大。

常见配方：`结果闪现 → 起点困境 → 关键过程 → 同条件对比 → 适用边界/CTA`。

## 口碑、案例与社会证明

额外检查：

- 证言者身份、初始怀疑、具体场景、可量化变化和证据来源。
- 真实反应与脚本化表演能否区分；评论、截图、数据是否可验证。
- 个案是否被错误推广为普遍结果。

常见配方：`原始异议 → 真实使用/经历 → 可验证结果 → 适用人群 → 低承诺下一步`。

## 娱乐、模因与反应内容

额外检查：

- 观众理解前提需要多少文化背景，笑点/惊奇点何时成立。
- 铺垫、重复、升级、节拍停顿和反应镜头是否精确。
- 模板中哪些是社区共享语法，哪些是某创作者独特表达。
- 改编是否加入新观点，而非只替换名词。

常见配方：`熟悉模板 → 一处违背预期 → 反应/升级 → 回扣或循环`。

## 新闻、热点与时效内容

额外检查：

- 事件、日期、人物、引用和来源必须实时核验。
- 区分事实、报道说法、推断和评论；标题不先定罪。
- 热点只是入口，必须说明与受众的实际关系或影响。
- 过期规则、平台趋势或实时数据需要联网验证。

常见配方：`发生了什么 → 为什么重要 → 已知证据 → 未知/争议 → 对受众影响 → 后续观察点`。
