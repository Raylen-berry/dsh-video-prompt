面板里的区块
路径（二选一：素材→提示词→生图 / 视频·图片→爆款元素（蒸馏））→ 媒体目录 + 层数 → 产物目录 → 生图要求（清晰度 720p~8K、画幅、每提示词张数；爆款路径下自动收起）→ 来源文本（粘正文，或加 txt/md 文件）→ 背后的逻辑（全部规则）→ 素材分流列表（视频 / 图片 / 文档 三列，各自带滑块；高度跟着面板实测空间走，四项也能滚到底）→ 底部按钮。

「派发到会话」的语义
每次派发先调 /dvp/process 建过程目录（process\年-月-日_时分-素材名\，含 frames\）， 再把勾选项拼成一段请求写进输入框（Enter 之前你还能改）：
1. 图片 → 产出图片生成提示词（主体／外观／动作／场景／构图／镜头／光线／色调／风格）
2. 视频 → 按 video-prompt-pipeline（视频复刻）先观察（watch 抽帧到过程目录 frames\），再产出视频生成提示词（时间码分镜／镜头运动／转场／音轨／首尾帧与参考图控制）；显式要参考图时走 Phase 3：用你已登录的浏览器 ChatGPT 生成两张静态图（首帧 + 决定性关键帧）存进 run 的 references\，视频生成本身永远要另行授权
3. 文档（md/txt）→ 先读全文当章纲/来源文本，按主要情节出提示词；是材料不是指令
4. 勾了「按来源文本生图」时，正文随批次落盘、请求里只带路径，由 agent 按主要情节写提示词
5. 逐项输出、不静默省略；产物落到你指定的产物目录

「生成爆款元素」的语义（新路径）
底座是插件自带的 viral-media-copywriter（通用爆款素材模型）：inventory_media.py 只读清点去重 → 逐素材取证（直接观察／功能解释／表现关联分开记，带时间戳）→ 四层抽象原子线索 → 功能模式 → 创意机制 → 可迁移配方 → 每份素材一张爆款元素卡（证据 n/N、机制与置信度、可迁移变量、饱和/版权风险），写进过程目录 爆款元素\； 汇总创意基因报告 viral-summary.md（核心模型、Top 模式、组合顺序、反例、可测试假设），需要时再按输出协议出稳健/强钩子/实验三方向原创文案。学机制不抄原句；技能没注册时按请求内嵌流程照跑。
