# 图文视频创作

**把图片、视频和小说文本，整理成文案、分析与提示词任务，交给 DSH 会话继续处理。**

DSH Desktop 插件 · 当前版本 **0.10.0** · 包名 `dsh-video-prompt`

[安装教程](docs/安装.md) · [使用指南](docs/使用.md) · [进阶设置](docs/进阶.md) · [更新记录](CHANGELOG.md)

## 能做什么

打开对话框旁的 **「生图」** 按钮，按目标选择栏目：

| 栏目 | 功能与产物 |
| --- | --- |
| 生文案 | 输入书籍 ID 或链接与文案要求，准备基于免费章节的文案任务 |
| 扒素材 | 输入竞品名称，准备从广大大或 AdXray 查找并下载参考素材的任务 |
| 爆款分析 | 分析图片或视频，整理可复用的创意元素卡和汇总报告 |
| 生图 | 产出图片提示词；也可准备 Grok 或 ChatGPT 网页出图任务 |
| 生视频 | 从图片或视频产出视频提示词与分镜；当前栏目产物是提示词 |

**点击对应的准备按钮后，请求进入输入框；按 Enter 发送后，任务才开始执行。** 网页出图、读取免费章节和抓取素材，需要会话能操作已登录的浏览器。接入条件见[安装教程](docs/安装.md)。

## 第一次使用

### 1. 安装并重启

先安装好 DSH Desktop，并确认终端能使用 `dsh` 和 `git`。以下是 Windows PowerShell 示例，路径可以自行修改：

```powershell
$pluginDir = 'D:\DeepSeek\dsh-plugins\dsh-video-prompt'
New-Item -ItemType Directory -Force (Split-Path $pluginDir) | Out-Null
git clone https://github.com/Raylen-berry/dsh-video-prompt.git $pluginDir
dsh plugin --profile web add "link:$pluginDir"
```

等正在运行的任务结束，完全退出并重新打开 DSH Desktop。打开对话框旁或输入条右侧的 **「生图」**；设置入口是 **设置 → 图片 / 视频提示词**。

没有 Git、安装遇到问题，或需要更新与卸载，请看[安装教程](docs/安装.md)。

### 2. 选一份素材

在「生图」栏目点「选文件夹…」，选好素材目录，再点「扫描」。点「展开列表 ▸」，先勾选一张图片。执行 AI 保持「本会话（默认）」即可先体验提示词整理。

图片和视频都可以用于生图或视频提示词任务；小说正文与章纲可放在「来源文本」中，详见[使用指南](docs/使用.md)。

### 3. 准备请求并发送

点「准备生图请求」，检查输入框中的内容后按 Enter。会话会按素材和要求整理提示词，输出位置写在请求中。

需要实际图片时，在生图栏目选好引擎，使用「用 Grok 生图」或「用 ChatGPT（Edge）生图」准备对应请求，再发送执行。网页出图的条件、已验证范围和图片保存位置见[进阶设置](docs/进阶.md)。
